# 阅读 - 安卓小说阅读器

一个简洁优雅的本地在线小说阅读App。

## 功能特性

### 阅读界面
- **智能分页**：使用 StaticLayout 自动计算文字换行，根据屏幕尺寸分页内容
- **点击区域交互**：屏幕分为三区，左侧点击上一页、右侧点击下一页、中间点击召唤/隐藏导航栏
- **滑动跨章**：左右滑动超过阈值时，自动跳转到上一章/下一章
- **底部留白**：内容底部向上提半行，避免文字紧贴边缘，阅读更舒适
- **夜间模式**：支持日/夜间模式切换，保护眼睛
- **字体大小调节**：支持 12sp ~ 28sp 自由调节字号
- **电量时间显示**：页脚显示当前页码、时间和电池电量
- **章节进度条**：底部进度条显示阅读进度，支持拖动跳转

### 章节目录
- **分页显示**：大书籍章节列表分屏显示，每页 50 章，保证打开速度
- **自动定位**：打开目录自动定位到当前章节所在页
- **最新章节标记**：最后一章显示「最新」标记
- **高亮当前章**：当前阅读章节蓝色高亮

### 其他功能
- **加入书架**：收藏喜欢的书籍到书架
- **离线下载**：批量下载所有章节到本地，无网也能读
- **进度保存**：自动保存阅读位置，下次打开继续阅读

## 核心算法说明

### 分页逻辑 (paginateAndDisplay)
1. 根据当前字体和屏幕宽度创建 TextPaint
2. 计算可用高度 = 屏幕高度 - 标题高度 - 页脚高度 - 半行高度
3. 使用 StaticLayout 计算最多能放多少行
4. 切割文字内容，重复直到全部内容切分完成
5. 更新适配器显示第一页

### 点击手势处理 (dispatchTouchEvent)
1. ACTION_DOWN 记录起始坐标
2. ACTION_UP 计算位移
3. 如果滑动距离足够大，处理跨章节跳转
4. 如果是轻触，判断落点区域：
   - 如果导航栏可见且点击落在顶栏/底栏 → 放行，让按钮响应
   - 左侧 1/3 → 上一页
   - 右侧 1/3 → 下一页
   - 中间 1/3 → 切换导航栏显示

### 章节目录分页 (showChapterListDialog)
1. 计算总页数 = (总章节数 + 每页大小 - 1) / 每页大小
2. 当前页 = 当前章节索引 / 每页大小，自动定位
3. 截取当前页的章节列表创建适配器
4. 点击章节跳转，点击上下按钮重新弹出对应页

## 交互说明

| 操作 | 效果 |
|------|------|
| 点击屏幕左侧 1/3 | 上一页 |
| 点击屏幕右侧 1/3 | 下一页 |
| 点击屏幕中间 1/3 | 显示/隐藏顶部底部导航栏 |
| 左右快速滑动 | 跨章节跳转 |
| 点击「目录」| 弹出章节目录对话框 |
| 拖动进度条 | 跳转到指定章节 |
| 点击「夜间模式」| 切换日/夜间主题 |
| 点击「设置」| 弹出字体大小调节对话框 |
